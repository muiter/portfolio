Copper Design System

Task
Create components and utilities for engineers to use throughout our codebase. Figure out how to engage engineers and have them use the design system.
Issue(s)
What do we add or leave out? To what degree should we allow control in a components structure?
Solution
We took a hybrid approach to development. After going through our developemnt cycle of creating a componet, we would then work with engineers to swap out old code for our newly built componets. We would also create merge requests so we knew what we could improve from making the components.
